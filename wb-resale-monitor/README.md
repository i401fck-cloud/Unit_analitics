# Resale Monitor — сканер WB Ресейл (Android)

Круглосуточно следит за поисками в разделе **Ресейл** на Wildberries и сразу присылает новые
объявления в Telegram — со скриншотом карточки, ценой и кнопкой «Открыть на WB».
Основан на Avito Monitor (`../avito-monitor`), ставится рядом с ним (другой applicationId).

> Приложение не связано с Wildberries и не является его официальным продуктом.

## Возможности

- Несколько поисков одновременно: у каждого своя ссылка, название, вилка цен, стоп-слова.
- Сортировка «по новинкам» (`sort=newly`) подставляется в ссылку автоматически.
- Первая проверка каждой ссылки — тихая, дальше приходят только новые товары.
- Скриншот карточки / страницы товара / фото / текст — на выбор.
- 💰 Цены рынка: медиана, средняя без выбросов, типичный диапазон, мин/макс.
- Управление кнопками в Telegram под полем ввода (статус, проверка, пауза, цены, скрин,
  поиски, настройки).
- Антибот-проверка WB («Почти готово…», «я не робот»): сигнал на телефоне, сообщение и
  скриншот в Telegram, пауза до прохождения проверки вручную в окне приложения.
- Адаптивный экран (внешний/внутренний экран складных телефонов, разделённый экран),
  ночной экран против выгорания OLED, работа 24/7.

## Парсинг

Страница загружается встроенным WebView, карточки читаются из DOM скриптом
`app/src/main/assets/parser.js`:

- карточки WB с `data-nm-id` / `id="c<ID>"`, ссылки `/catalog/<ID>/detail.aspx`,
  а также любые ссылки с числовым ID товара (на случай отдельной вёрстки Ресейла);
- текущая цена (`price__lower-price`), зачёркнутая старая цена игнорируется;
- название = бренд / наименование.

Если по поиску найдено 0 карточек на непустой странице, бот один раз присылает файл
`diag-….txt` (ссылки, частые CSS-классы, вёрстка вокруг первой цены) — по нему парсер
подстраивается под реальную вёрстку.

## Сборка APK

Workflow `.github/workflows/wb-resale.yml` собирает APK при каждом push в `wb-resale-monitor/`.
Скачать: вкладка **Actions** → **Build WB Resale Monitor APK** → **Artifacts**.
Стабильная подпись — как в Avito Monitor (секреты `KEYSTORE_BASE64` и др.).

## Настройка

1. Создайте отдельного бота у @BotFather (чтобы не смешивать с ботом Avito Monitor).
2. В приложении: Настройки → токен, Chat ID → «Добавить поиск» (ссылка из раздела Ресейл).
3. «Старт» на вкладке «Обзор». В Telegram появятся кнопки (если нет — отправьте `/start`).
